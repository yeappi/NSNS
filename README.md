# NSNS — Not SNS

階層とタグで整理できる、トーク風のメモアプリ。
蓄積したメモを条件で抜き出して、まとめてコピー・書き出しできるのが本体。

- 1ファイル（`index.html`）で動く。ビルド不要
- データはブラウザ内（IndexedDB）に保存
- 書き出し：コピー / .md / 画像込み .zip / 画像込み .html

## 分類・一覧・AI連携（試作）
- メモに「種類」（タスク／出来事／資料／アイデア／疑問／感想）・「状態」（未確定／確定／完了）・ピンを付けられる（長押し → 分類、またはメモのメニュー）
- ホームの「一覧」で、トークをまたいで種類・状態・ピン・タグ・本文で絞り込み
- 書き出しの詳しい条件で `@タスク` `@未分類` `@確定` `@ピン` なども使える
- AIとはコピペでやりとり：トーク／フォルダのメニュー「AIで整理する」からプロンプトをコピー → AIと会話して「確定」→ 出てきたJSONを「＋ → AIの結果を取り込む」に貼る
  - 分類（種類・状態・タグを付与。自分で付けた種類・状態は上書きしない）
  - ブレスト（論点ごとにトークを作り、AIの問いを置く）／次の問い（答えを踏まえて追加）
  - 資料化（まとめを「資料」トークへ。終わったトークはアーカイブ）
- 取り込みは1回ずつ取り消せる（設定 → AIの結果を取り込む → 最近の取り込み）

## 問いかけ（💡・試作）
- 入力欄の 💡 から、はたらき8種（吐き出す／広げる／深める／整える／見直す／決める／動く／振り返る）を選ぶと、問いが左の吹き出しで出る
- 吐き出すは分野（汎用・やること・気持ち・望み・気づき・仕事）で絞れる
- 「次」（ボタン or 入力）で飛ばす。答えた問いだけトークに残る（💡印・書き出しには含まれない）
- 「自動で次へ」オンで、1件書くたびに次の問い
- 1周するまで同じ問いは出ない。問いは #1〜#195 の固定番号
- 統計（表示・次・答えた回数）は端末内。設定の「NSNS」を5回タップでコピー

## 思考法・アナウンス・AI思考法（試作）
- 💡の下半分に思考法（いつもの5つ＋お気に入り、「もっと見る」で22個・☆でお気に入り）
- 選ぶと元のトークのすぐ下に「元の名前｜思考法」のトークを作り、順番に問いを出す。繰り返し型は「もう十分」で抜ける
- 枠ごと・対象ごとに分ける型（SWOT・KPT・アイゼンハワー・6つの帽子・SCAMPER・プロコン）は、元の名前のフォルダを作って部屋を分ける（同名フォルダの中ならそれを使う）
- メモを左にスワイプ → 📢アナウンス／💬トークにする（長押しメニューにも同じもの）。アナウンスはトークの上に1行で出る
- トーク／フォルダの「AIで整理する」→「AI思考法で問いを作る」でレベル1〜5。JSONを取り込むと、おすすめがトークの上と💡に出て、専用の問いのトークができる

## ナビ・inbox・お気に入り（試作）
- 下のナビ：メモ／inbox／データ。トークを開いている間は隠れる（スマホ）
- inboxタブ：書くだけの画面。送るとホーム最上段の「inbox」トークに入る（部屋は開かない）。吐き出しの問いを上に出す（次／✕）
- inboxトークは最初に送ったときに作られる。バッジは初期オフ。消す・移動・アーカイブはできない
- トーク／フォルダのメニュー「⭐お気に入り」で、ホームのinboxのすぐ下に並ぶ
- フォルダに中身の数（💬トーク 📁フォルダ 🗄アーカイブ）と、思考法・AIの問いのトークに答えた数（✅2/4）
- データタブ：ビュー（下の「データタブ：ビュー」）。右上の🔍で、従来の細かい一覧（本文・種類・状態・タグ・ピン）を開く

## テスト用サンプル
- 設定（右上のNSNS）→「🧪 テスト用サンプルを入れる」で、今のメモに触らずに「テスト用サンプル」フォルダを追加
- 中身：分類・状態・タグ・アナウンス付きのメモ、仕事・考えごと・暮らしの3トーク（種類・状態・タグ・日付が約2か月分ばらけたメモ）、月をまたぐ資料、アーカイブinboxの整理済みメモ、アーカイブしたフォルダ、保存済みビュー3つ（まだビューが無いときだけ）、途中まで答えた5Why、SWOT（枠ごとの部屋）、ブレスト（自由メモ＋AIの問い）、AIのおすすめ付きトーク、💡問いかけの例、資料、アーカイブ済みトーク、⭐お気に入り。inboxがまだ無ければinboxにも少し入る
- 空の状態の「サンプルで試す」でも同じものが入る。いらなくなったらフォルダごとごみ箱へ

## データタブ：ビュー（試作）
- 「束ね方」と「フィルタ」でメモを横断して見る。束ね方は1つ選ぶ（種類別／タグ別／資料化の月別／まとめて1室）、フィルタは重ねがけ（期間・状態・種類・タグ）
- 束ねた項目（例：☑️タスク）を開くと、そこだけを集めた**抽出ルーム**。トークと同じ吹き出しで並び、元のトーク名が上に出る。条件で毎回引いて表示するだけでコピーは作らない。タップで元のトークへ
- 抽出ルームの入力欄で書くと、ビューの条件（種類・状態・タグ・アナウンス）の印を付けて**アーカイブinbox**に保存。条件が1つに決まらないときは印なし（その場合はビューに出ない旨を知らせる）。資料化の月別は見るだけ
- 絞り込みは抽出ルーム右上の ⚲ で開く
- データタブの最初の画面：⭐お気に入り → **種類別のトークルーム**（タスク・疑問・アイデア…が件数と最新1行つきで直接並び、タップで抽出ルーム）→ ほかの見方 → マイビュー
- ほかの見方：タグ別／資料化の月別／未完了のタスク／今週のメモ／アナウンス一覧／全部まとめて（種類別は、別の束ね方から切り替えて開ける）
- 💾で保存（ビュー全体、または開いている抽出ルームだけ）。★でお気に入り→データタブの先頭に並ぶ。保存済みビューはフィルタ変更が自動で反映される
- 保存先は端末内（localStorage の `views`）。Supabase同期にはまだ乗っていない
- タグ別は、複数タグのメモが複数の部屋に出る。資料化の月別は「資料」トークのメモを月ごとに束ねる

## アーカイブ帯・アーカイブinbox（試作）
- 一覧の最後尾の「🗄 アーカイブ」帯に、アーカイブしたトーク・フォルダ・アーカイブinboxが入る
- フォルダもアーカイブできる（中のトークごとビューから外れる。ビューの「アーカイブも」で含められる）
- inboxのメモに種類が付くと（自分で分類／AIの分類の取り込み）、アーカイブinboxへ自動で移る。直前の💡問いも一緒。元に戻せる。AI分類の取り込みを取り消すと、inboxに戻る
- アーカイブinboxは消す・移動・アーカイブ解除ができない。中身が無いうちは帯に出ない。ビューには普段から出る
- inbox以外のトーク・フォルダは、整理しても自動ではアーカイブされない

## 使い勝手の見直し（UXパス）
- 抽出ルーム：メモをタップ → 種類・状態のチップ（1タップで付く・元に戻せる）＋メニュー（元のトークで開く・選択・アナウンス・移動・ごみ箱）。…→「選択する」でまとめて分類・完了・AI・移動・削除
- 抽出ルーム：完了したメモは普段隠す（「✓ 完了したn件を表示」で薄く表示）。未分類の部屋には「選んで分類／AIで分類」の帯
- 絞込はヘッダー下に固定表示。本文検索も絞込の中に（右上の🔍は「全部まとめて」を検索つきで開く。旧・細かい一覧のボタンは廃止）
- タグ別：1件だけのタグは「その他のタグ」にまとめる。ビューの行の説明は中身の例（#思考・#仕事…）
- inbox：トークの上に「未整理 n件 → 1件ずつ仕分ける／AI」。仕分けは種類を選ぶと次のメモへ（スキップ可）。空になると「✨ inboxは空です」
- inboxタブ：入力欄を小さくし、送るボタンを入力欄のすぐ下へ。下に直近3件と未整理の数。💡の問いのボタンは問いの下に
- トーク：種類は吹き出しの左上に小さなアイコンで（チップの行が減って1メモが短く）。長押しメニューの上に種類・状態のチップ
- トークのヘッダー：まとめて選択は「…」メニューへ。思考法のトークは名前の下に思考法名
- 検索：ヒットした語をハイライト、本文を主役に
- 一覧の最後に余白（＋ボタンと重ならない）。アーカイブinboxは帯の中でも普通の濃さ。シートが開いているときの通知は画面の上に

## AIに頼む・取り込み（見直し）
- 入口は「🤖 AIに頼む」1つ（トーク／フォルダの「AIで整理する」、選択したメモ、データタブのビュー）。上に渡すもの（トーク何個・メモ何件）を表示
- 送るたびに「送った記録」を残す（端末内 `aiSent`）。AIには短い番号（m1, r1）と ref だけを渡し、取り込み時に本物のIDへ戻す。古い形式（長いID）のJSONも読める
- 結果待ちの間は、ホーム・トーク・データタブの上に「🤖 ◯◯の結果待ち」。タップで取り込む／もう一度コピー／やめる
- 分類は80件ずつ。返ってこなかった分・チェックを外した分・残りは「続き」としてコピーできる
- 分類は最初からJSONを出させる（判断に迷う組み合わせの決め方つき）。ブレスト・思考法・次の問い・資料化は「相談→確定」、プロンプトの最後に「すぐ」と書けばいきなりJSON
- ブレストは送ったメモのあるフォルダに作る（取り込むときに開いている場所ではなく）
- 資料化の本文は lines（1行＝1要素）。text も読める
- 取り込み前の確認で、分類の行・ブレストの論点・次の問いのトークをチェックで外せる
- JSONが壊れている／途中で切れているときは「AIに直してもらう文をコピー」

## 書き出し＝AIに頼む（統合）
- 入口は「↗ 書き出す」1つ（トークのヘッダー、トーク／フォルダの「AIに頼む・書き出す」、選択、データタブのメニュー）
- シンプルタブ：テンプレートのボタン（そのままコピー／未分類を分類／話題ごとに分解／表にする／資料にまとめる／ブレスト＋自分のテンプレート）。押すとすぐコピー。数字は渡すメモの件数
- 詳細タブ：何を（範囲・タグ・状態・詳しい条件）→ どう渡す（そのまま・分類・分解・データ化・資料化・ブレスト・次の問い・AI思考法）→ レベル → 出力
- レベル：分解・データ化・資料化は「原文を残す／整える／まとめる」、AI思考法は1〜5
- 「＋ テンプレートとして保存」：頼み方とレベル・出力の形式を保存。範囲と条件も覚えるかは選べる（オフなら開いた場所のメモに使える）。長押しで削除。前に保存した条件はそのまま「そのまま」のテンプレートとして残る
- 分解：1件に混ざった話題を1件1話題に。分けたメモは元と同じ位置に並び、元のメモはごみ箱へ（取り消すと戻る）。80件ずつ
- データ化：日付・金額などを列に揃えた表を「資料」トークに入れる（吹き出しに表で表示、データタブの「資料」にも出る）
- 開いたタブは次回も同じタブで開く

### 書き出しボタンの独立（データタブ）
- データタブのビュー／抽出ルームのヘッダーにも ↗ ボタン（他画面と同じ）を追加
- 「AIに頼む」の重複入口を整理：メニュー・選択バーの「AI」は書き出し画面（シンプルタブ）に統一

### AIと相談（汎用プロンプト）
- 書き出し画面に「💬 AIと相談」を追加（詳細タブの頼み方の先頭、シンプルタブのテンプレートにも）
- 何をするかはAIとの会話で決める。確定するたびにAIが分類・分解・データ化・資料化・ブレストのどれかのJSONを返し、取り込み側が type を見て自動で振り分ける
- 送った記録は取り込み後も残り、同じ会話から何回でも取り込める（結果待ちの札から「終える」で閉じる）
- 分解を取り込むと、分けたメモを m2-1, m2-2 … として記録。その後の分類などで AI がこの番号を使っても取り込める
- メモの日付は ( ) で本文と分け、「本文に含めない」と明記
- 「プロンプトだけ」ボタン：JSONの説明も番号もない、相談用の文だけをコピー（記録は作らない）

### 見た目と使い勝手の整理（ごちゃつき対策）
- トークのヘッダーに🏷「整理モード」：1回タップで切り替え。普段は本文と時刻だけ、整理モードで種類・状態・タグをチップで表示（タップで付け替え）。状態は端末に記憶
- 吹き出しは白、未書き出しバッジはグレーに。オレンジは主役の操作だけ
- 1日1件のメモは日付の区切りを出さず、時刻の横に日付
- 長押し・「…」メニューは共通の型：編集／書き出す／移動／削除のアイコン＋種類＋「その他」（たたんで表示）
- 書き出し画面：タブを廃止。主役は「AIと相談」、続いて「そのままコピー」「ファイルに保存」、下に決まった頼み方。範囲・条件は「範囲・条件を変える」の別ページ（テンプレート保存もここ）
- AIの答え待ちは、画面下の「貼って取り込む」バー（1タップでクリップボードから読んで取り込み画面へ）
- ホーム：ヘッダーから選択を外し＋メニューへ（AI取り込みは＋から外した）。フォルダは件数だけ表示
- データ：絞り込みは閉じているとき1行の要約、タグは6個＋「もっと」。元トーク名は変わったときだけ。保存ボタンを線アイコンに。入力欄は「☑️タスク として書く」
- バックアップの帯はメモ40件から。設定のテスト用サンプルは「NSNS」5回タップで表示
- データのビュー：束ね方は「種類・タグ・月・1室」の切り替えバー、絞り込みは1行の要約→「変更」でラベル付きのシート（「N件を表示」）。本文検索はヘッダーの🔍、保存は☆（お気に入りで★）。見出しの下は「件数 · 期間」。未分類は点線のカード

### 新しい版の知らせ
- 開いている間に本番が更新されたら、画面の上に「新しい版があります［更新］」を表示（アプリに戻ったとき・10分ごとに確認。押すまで何も変えない）
- 確認は `/index.html?_v=…` を直接取りに行く（sw.js はこの形を素通しし、控えにも残さない）。控えの名前を v4 に上げ、古い控えは自動で消える

## タスクの管理（チェック）

- 種類が「タスク」のメモの左に○が付き、1タップで完了（取り消し線＋薄く）、もう一度タップで未完了に戻る
- 状態の選択肢はタスクだけ「未完了／完了」の2つ
- データ → ☑️タスク は未完了のみ表示（完了は「完了した◯件を表示」で出せる）。件数も未完了数
- 期限・通知は未対応（データ形式は変更なし）

## ルールだけコピー

- 書き出し画面と「＋」メニューの「ルールだけコピー／AIの会話をメモにする」で、メモなしの取り込みルール（JSON形式）だけをコピーできる
- 使っているAIとの会話の続きに貼って「ここまでをNSNS用に整えて」と相談 → 確定でJSONが返る → 「貼って取り込む」で、トークとメモ（種類・状態・タグ付き）が作られる（取り消し可）
- メモ付きでコピーするだけの「プロンプトだけ」は廃止

## 更新バーの基準を修正

- 「新しい版があります」の基準を、起動時に取った最新版ではなく「今動いているページ自身のコード」にした。古い画面のまま開いたアプリでも、最新版と違えば更新バーが出る

## ルールだけコピーを完全版に

- メモなしでも、AIと相談と同じ進め方（目的を聞く→選択肢→案→直す→確定でJSON）で、できることをすべて持たせた：メモにする／ブレスト（フォルダ＋問い付きトーク）／AI思考法（カタログ＋レベル）／データ化／資料化。既存のタグ・フォルダ名も渡す（メモ本文は渡さない）
- `memos` 形式に `folder`・`questions`・`method` を追加。データ化・資料化は元メモの指定なしでも取り込める
- ルールだけの記録は「相談」と同じく残り、何回でも取り込める
- AIと相談にも「次の問い」「AI思考法」の返し方を追加
