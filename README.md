# NSNS — Not SNS

階層とタグで整理できる、トーク風のメモアプリ。
蓄積したメモを条件で抜き出して、まとめてコピー・書き出しできるのが本体。

- 1ファイル（`index.html`）で動く。ビルド不要
- データはブラウザ内（IndexedDB）に保存
- 書き出し：コピー / .md / 画像込み .zip / 画像込み .html

## 分類・一覧・AI連携（試作）
- メモに「種類」（タスク／出来事／資料／アイデア／疑問／感想）・「状態」（未確定／確定／完了）・ピンを付けられる（長押し → 分類、またはメモのメニュー）
- ホームの「一覧」で、トークをまたいで種類・状態・ピン・タグ・本文で絞り込み
- 書き出しの詳しい条件で `@タスク` `@未分類` `@確定` `@ピン` なども使える
- AIとはコピペでやりとり：トーク／フォルダのメニュー「AIで整理する」からプロンプトをコピー → AIと会話して「確定」→ 出てきたJSONを「＋ → AIの結果を取り込む」に貼る
  - 分類（種類・状態・タグを付与。自分で付けた種類・状態は上書きしない）
  - ブレスト（論点ごとにトークを作り、AIの問いを置く）／次の問い（答えを踏まえて追加）
  - 資料化（まとめを「資料」トークへ。終わったトークはアーカイブ）
- 取り込みは1回ずつ取り消せる（設定 → AIの結果を取り込む → 最近の取り込み）

## 問いかけ（💡・試作）
- 入力欄の 💡 から、はたらき8種（吐き出す／広げる／深める／整える／見直す／決める／動く／振り返る）を選ぶと、問いが左の吹き出しで出る
- 吐き出すは分野（汎用・やること・気持ち・望み・気づき・仕事）で絞れる
- 「次」（ボタン or 入力）で飛ばす。答えた問いだけトークに残る（💡印・書き出しには含まれない）
- 「自動で次へ」オンで、1件書くたびに次の問い
- 1周するまで同じ問いは出ない。問いは #1〜#195 の固定番号
- 統計（表示・次・答えた回数）は端末内。設定の「NSNS」を5回タップでコピー

## 思考法・アナウンス・AI思考法（試作）
- 💡の下半分に思考法（いつもの5つ＋お気に入り、「もっと見る」で22個・☆でお気に入り）
- 選ぶと元のトークのすぐ下に「元の名前｜思考法」のトークを作り、順番に問いを出す。繰り返し型は「もう十分」で抜ける
- 枠ごと・対象ごとに分ける型（SWOT・KPT・アイゼンハワー・6つの帽子・SCAMPER・プロコン）は、元の名前のフォルダを作って部屋を分ける（同名フォルダの中ならそれを使う）
- メモを左にスワイプ → 📢アナウンス／💬トークにする（長押しメニューにも同じもの）。アナウンスはトークの上に1行で出る
- トーク／フォルダの「AIで整理する」→「AI思考法で問いを作る」でレベル1〜5。JSONを取り込むと、おすすめがトークの上と💡に出て、専用の問いのトークができる

## ナビ・inbox・お気に入り（試作）
- 下のナビ：メモ／inbox／データ。トークを開いている間は隠れる（スマホ）
- inboxタブ：書くだけの画面。送るとホーム最上段の「inbox」トークに入る（部屋は開かない）。吐き出しの問いを上に出す（次／✕）
- inboxトークは最初に送ったときに作られる。バッジは初期オフ。消す・移動・アーカイブはできない
- トーク／フォルダのメニュー「⭐お気に入り」で、ホームのinboxのすぐ下に並ぶ
- フォルダに中身の数（💬トーク 📁フォルダ 🗄アーカイブ）と、思考法・AIの問いのトークに答えた数（✅2/4）
- データタブ：ビュー（下の「データタブ：ビュー」）。右上の🔍で、従来の細かい一覧（本文・種類・状態・タグ・ピン）を開く

## テスト用サンプル
- 設定（右上のNSNS）→「🧪 テスト用サンプルを入れる」で、今のメモに触らずに「テスト用サンプル」フォルダを追加
- 中身：分類・状態・タグ・アナウンス付きのメモ、仕事・考えごと・暮らしの3トーク（種類・状態・タグ・日付が約2か月分ばらけたメモ）、月をまたぐ資料、アーカイブinboxの整理済みメモ、アーカイブしたフォルダ、保存済みビュー3つ（まだビューが無いときだけ）、途中まで答えた5Why、SWOT（枠ごとの部屋）、ブレスト（自由メモ＋AIの問い）、AIのおすすめ付きトーク、💡問いかけの例、資料、アーカイブ済みトーク、⭐お気に入り。inboxがまだ無ければinboxにも少し入る
- 空の状態の「サンプルで試す」でも同じものが入る。いらなくなったらフォルダごとごみ箱へ

## データタブ：ビュー（試作）
- 「束ね方」と「フィルタ」でメモを横断して見る。束ね方は1つ選ぶ（種類別／タグ別／資料化の月別／まとめて1室）、フィルタは重ねがけ（期間・状態・種類・タグ）
- 束ねた項目（例：☑️タスク）を開くと、そこだけを集めた**抽出ルーム**。トークと同じ吹き出しで並び、元のトーク名が上に出る。条件で毎回引いて表示するだけでコピーは作らない。タップで元のトークへ
- 抽出ルームの入力欄で書くと、ビューの条件（種類・状態・タグ・アナウンス）の印を付けて**アーカイブinbox**に保存。条件が1つに決まらないときは印なし（その場合はビューに出ない旨を知らせる）。資料化の月別は見るだけ
- 絞り込みは抽出ルーム右上の ⚲ で開く
- データタブの最初の画面：⭐お気に入り → **種類別のトークルーム**（タスク・疑問・アイデア…が件数と最新1行つきで直接並び、タップで抽出ルーム）→ ほかの見方 → マイビュー
- ほかの見方：タグ別／資料化の月別／未完了のタスク／今週のメモ／アナウンス一覧／全部まとめて（種類別は、別の束ね方から切り替えて開ける）
- 💾で保存（ビュー全体、または開いている抽出ルームだけ）。★でお気に入り→データタブの先頭に並ぶ。保存済みビューはフィルタ変更が自動で反映される
- 保存先は端末内（localStorage の `views`）。Supabase同期にはまだ乗っていない
- タグ別は、複数タグのメモが複数の部屋に出る。資料化の月別は「資料」トークのメモを月ごとに束ねる

## アーカイブ帯・アーカイブinbox（試作）
- 一覧の最後尾の「🗄 アーカイブ」帯に、アーカイブしたトーク・フォルダ・アーカイブinboxが入る
- フォルダもアーカイブできる（中のトークごとビューから外れる。ビューの「アーカイブも」で含められる）
- inboxのメモに種類が付くと（自分で分類／AIの分類の取り込み）、アーカイブinboxへ自動で移る。直前の💡問いも一緒。元に戻せる。AI分類の取り込みを取り消すと、inboxに戻る
- アーカイブinboxは消す・移動・アーカイブ解除ができない。中身が無いうちは帯に出ない。ビューには普段から出る
- inbox以外のトーク・フォルダは、整理しても自動ではアーカイブされない
